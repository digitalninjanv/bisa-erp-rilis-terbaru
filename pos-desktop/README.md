# POS Desktop (Experimental Standalone Prototype)

> [!NOTE]
> Paket desktop resmi yang aktif dan didukung untuk operasional kasir adalah **`pos-electron/`**.
> Direktori `pos-desktop/` merupakan prototipe statis standalone berbasis Tauri/Next.js export.

Untuk rilis dan instalasi desktop kasir toko, gunakan panduan pada [pos-electron/README.md](../pos-electron/README.md).
