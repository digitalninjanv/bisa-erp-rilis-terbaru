Pengaturan Printer & Server

Atur printer thermal kasir dan alamat server Bisa ERP.

Pastikan printer USB atau LAN sudah ditambahkan di pengaturan printer Windows/Linux.

Lebar Kertas Thermal
Tips Laci Kasir (RJ-11): Aplikasi desktop mencetak lewat driver sistem operasi. Aktifkan opsi Open Cash Drawer / Kick Drawer pada pengaturan driver printer di Windows/CUPS agar laci terbuka otomatis.

Gunakan HTTPS untuk server cloud, atau HTTP untuk jaringan lokal (localhost / 192.168.x.x / .local).
